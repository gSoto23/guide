# Data Model: Guide Builder

**Feature**: [spec.md](spec.md) · **Plan**: [plan.md](plan.md) · **Decisions**: [research.md](research.md)

Conventions (same as features 001 and 002):

- IDs are UUIDs generated by the database. Timestamps are `timestamptz` in UTC.
- **Every new table is tenant-owned:** it carries `workspace_id`, RLS is enabled and forced, and
  the RLS migration check covers it (SEC-14).
- **Writes** need `properties.manage` (owners and admins); reveals and the public Wi-Fi switch
  need `restricted.reveal` ([research R18](research.md#r18-roles-step-up-and-limits)). Every member
  reads guides.
- **Restricted columns** (`*_ciphertext`) follow 002: AES-256-GCM under the workspace data key,
  never in responses, logs, snapshots, or AI inputs.
- **Documents** (`jsonb` columns named `doc`) are validated against the content schema of
  [research R2](research.md#r2-content-model-items-with-a-rich-text-document-per-language) on every
  write.
- Languages are `es` or `en` (002 `GUIDE_LANGUAGES`).

## 2. Locked fields

### Changes to `restricted_value` (from feature 002)

The table keeps its name; the product calls its rows **locked fields**.

| Field | Change | Rules |
|---|---|---|
| `label` | now required, ≤ 80 | Defaults to the kind's name in the main language |
| `source` | adds `host` and `copy` | `copy`: created by duplication with no value (FR-067) |
| `value_ciphertext`, `data_key_id` | now nullable | Null means "not set" |
| `public_value` | new, text ≤ 200, nullable | Only `wifi_password`, only when the host made it public (FR-021). `CHECK`: `public_value` and `value_ciphertext` are never both set |
| `section_kind` | new, enum (section kinds), default by kind | Where the field is listed: Arrival and access, Wi-Fi, or another section |
| `value_set_at`, `updated_by` | new | "Set by Ana, 2 days ago" (FR-016) |

**Rules:**

- A value is at most 200 characters (FR-015). Reads through the API return kind, label, section,
  whether it is set, `value_set_at`, and the editor's name; never the value or `public_value`
  except through the reveal route (R4) and, for a public Wi-Fi password, the guide's Wi-Fi
  content.
- **Re-import (FR-022):** an import sets the value only when it is null; `host` rows are never
  overwritten.
- **RLS:** members of the workspace read the non-restricted columns through the
  `restricted_value_public` view; the ciphertext and `public_value` columns are granted only to
  the API's write and reveal paths.

## 6. Security log, retention, and deletion

**Security log events** (added to the catalog, allowlisted fields only):
`restricted_value.added`, `.changed`, `.deleted`, `.revealed`, `.reveal_limited`,
`.made_public`, `.made_locked` (property ID, field ID, kind); `guide.published`,
`guide.unpublished`, `guide.version_restored` (property ID, version number);
`shared_block.published`, `shared_block.deleted` (block ID, section kind, guides updated).

| Data | Kept | Deleted by |
|---|---|---|
| Voice recordings | Until transcribed, at most 24 hours | `interview.answer`; uploads bucket lifecycle (1 day) |
| Documents and photos read for knowledge | Until read, at most 24 hours | `guide.document`; lifecycle |
| Transcripts, answers, document text | 7 days | `retention.daily` |
| Published versions | Latest 20 per guide | `retention.daily` |
| Media | While an item, a block, or a kept version references it, plus 24 hours | Media sweep in `retention.daily` |
| AI request rows | 12 months | `retention.daily` |
| Locked fields | Until the host deletes them or the property is purged | API; `properties.purge` |

**Property removal (FR-068):** a removed property's guide is not served (spec 004 reads only
`active` properties). `properties.purge` deletes the guide with its sections, items, versions,
links, documents, interview data, locked fields, and the media objects only it references.

## 7. State machines

### Guide

```text
draft ──publish──▶ published ──unpublish──▶ unpublished ──publish──▶ published
                       │  ▲
          draft write  │  │ publish (clears has_unpublished_changes)
                       ▼  │
              published + has_unpublished_changes
```

Shared-block fan-out writes a new version for `published` guides only and leaves
`has_unpublished_changes` as it was.

### Item review

```text
created by import, listing, document, interview, or copy ──▶ needs review (reviewed_at null)
needs review ──edit or Approve──▶ reviewed
created by the host ──▶ reviewed
```

### Translation (per item and non-source language)

```text
current(machine) ──source changes──▶ stale ──job ok──▶ current(machine)
current(reviewed) ──source changes──▶ out_of_date ──"Translate again"──▶ stale
                                                  └─"Keep as is"──▶ current(reviewed)
stale ──daily limit or AI unavailable──▶ pending ──retry──▶ stale
stale ──tokens mismatch twice──▶ failed ──"Translate again"──▶ stale
any ──host edits the translation──▶ current(reviewed)
```

### Interview turn

```text
queued ──voice──▶ transcribing ──▶ drafting ──▶ done
queued ──text──▶ drafting ──▶ done
transcribing | drafting ──error──▶ failed (question stays open)
```

### Media object

```text
uploading ──complete──▶ processing ──scan ok and processed──▶ ready
processing ──bad type, too long, malware, or over the limit──▶ rejected
```

### Guide document

```text
checking ──scan ok and type ok──▶ reading ──▶ done (suggestions created, or nothing_found)
checking | reading ──error──▶ rejected (with reason)
```

## 8. Validation rules mapped to requirements

| Rule | Requirement |
|---|---|
| Nine default sections created with every property, unique per guide | FR-001 |
| ≤ 10 custom sections; default sections not deletable | FR-002 |
| Document schema: allowed nodes, marks, and link schemes only | FR-008, AC-SEC-008 |
| Images ≤ 10 MB, ≤ 20 per section; videos ≤ 90 s, ≤ 150 MB, ≤ 3 per section | FR-009 |
| ≤ 20,000 characters per section and language | FR-010 |
| Section revision checked on every write | FR-012 |
| Recommendation benefit answer required before approval | FR-014 |
| Locked value ≤ 200 characters; door, gate, lockbox, and alarm codes never public | FR-015, FR-021 |
| ≤ 20 reveals per member per hour | FR-018 |
| Snapshots and AI inputs never hold locked values | FR-019, FR-025 |
| Answers ≤ 2,000 characters; voice ≤ 2 minutes | FR-035 |
| PDFs ≤ 20 MB and 60 pages; ≤ 10 files at once; encrypted PDFs rejected | FR-039 |
| Publish needs `property.setup_status = ready` and no pending deletion | FR-049 |
| ≤ 50 shared blocks; no locked fields in shared blocks | FR-057 |
| Daily AI limit and media storage limit | FR-064, FR-065 |
