# Data Model: In-Guide AI Chat

**Feature**: [spec.md](spec.md) · **Plan**: [plan.md](plan.md) · **Research**: [research.md](research.md)

One migration pair: `0023_guide_chat.sql` (tables, generated by drizzle-kit) and
`0024_guide_chat_rls.sql` (RLS, grants). Every new table is tenant-owned, with RLS enabled and forced
(SEC-14). Request context: every member of the workspace reads conversations, messages, drafts, and
the member projection of traces; owners, admins, and agents (`conversations.handle`) write replies and
draft actions. System context: guest routes after resolving the guide (spec 004 R12), the worker, and
retention.

## 1. Conversations

### `conversation`

| Column | Type | Rules |
|---|---|---|
| `id` | `uuid` PK | |
| `workspace_id` | `uuid` FK → `workspace` | `ON DELETE CASCADE` |
| `property_id` | `uuid` FK → `property` | `ON DELETE CASCADE` |
| `stay_id` | `uuid` FK → `stay` | `ON DELETE SET NULL`; set when the device has a stay session |
| `cookie_hash` | `text` | SHA-256 hex of the chat cookie; `CHECK (cookie_hash ~ '^[0-9a-f]{64}$')` |
| `status` | `text` | `open` or `needs_host`. Default `open` |
| `needs_host_reason` | `text` | `emergency`, `malfunction`, `complaint`, `money`, `reservation_change`, `legal`, `not_confident`, `draft_ready`, `check_failed`, `limit`, `unavailable`; required when `needs_host` |
| `language` | `text` | The guide language the guest uses (`es` or `en`) |
| `last_message_at` | `timestamptz` | |
| `last_notified_at` | `timestamptz` | For the 30-minute email rule (FR-023) |
| `created_at` | `timestamptz` | |

- Unique `(property_id, cookie_hash)`. Index `(property_id, status, last_message_at DESC)`.
- `CHECK ((status = 'needs_host') = (needs_host_reason IS NOT NULL))`.

### `chat_message`

| Column | Type | Rules |
|---|---|---|
| `id` | `uuid` PK | |
| `workspace_id` | `uuid` FK | `ON DELETE CASCADE` |
| `conversation_id` | `uuid` FK → `conversation` | `ON DELETE CASCADE` |
| `seq` | `bigint` | Increasing per conversation (cursor for polling) |
| `author` | `text` | `guest`, `assistant`, `host` |
| `kind` | `text` | `text`, `holding`, `emergency`, `pointer`, `greeting`, `pause` |
| `body` | `text` | `CHECK (char_length(body) BETWEEN 1 AND 4000)`; guest messages ≤ 2,000 (checked in the API) |
| `payload` | `jsonb` | Structured extras: emergency numbers and contacts, cited section IDs and titles |
| `author_user_id` | `text` FK → `user` | For host messages and sent drafts; `ON DELETE SET NULL` |
| `client_id` | `text` | Guest retries (idempotency); unique per conversation when set |
| `created_at` | `timestamptz` | |

- Unique `(conversation_id, seq)`; unique `(conversation_id, client_id)` where not null.

## 2. Drafts and traces

### `agent_draft`

| Column | Type | Rules |
|---|---|---|
| `id` | `uuid` PK | |
| `workspace_id` | `uuid` FK | `ON DELETE CASCADE` |
| `conversation_id` | `uuid` FK | `ON DELETE CASCADE` |
| `trace_id` | `uuid` FK → `agent_trace` | |
| `body` | `text` | The assistant's proposed answer |
| `section_ids` | `uuid[]` | Sources |
| `status` | `text` | `open`, `sent`, `edited`, `superseded`, `discarded` |
| `acted_by` | `text` FK → `user` | `ON DELETE SET NULL` |
| `acted_at` | `timestamptz` | |
| `created_at` | `timestamptz` | |

- Partial unique index `(conversation_id) WHERE status = 'open'` (one open draft per conversation).

### `agent_trace`

| Column | Type | Rules |
|---|---|---|
| `id` | `uuid` PK | |
| `workspace_id`, `conversation_id` | FKs | `ON DELETE CASCADE` |
| `guest_message_id` | `uuid` FK → `chat_message` | The message that triggered it |
| `reply_message_id` | `uuid` FK → `chat_message` | When a reply was sent; null for drafts and holds |
| `classification` | `jsonb` | language, topic, escalation, sentiment, injection |
| `decision` | `text` | `answered`, `drafted`, `held`, `pointer`, `greeting`, `paused` |
| `reason` | `text` | The needs-host reason, when any |
| `autonomy` | `text` | `draft` or `auto` in force |
| `guide_version_id` | `uuid` FK → `guide_version` | `ON DELETE SET NULL` |
| `section_ids` | `uuid[]` | |
| `checks` | `jsonb` | `[{check, passed}]` |
| `model` | `text` | Null when no model ran |
| `input_tokens`, `output_tokens`, `cache_read_tokens`, `cache_write_tokens` | `integer` | |
| `cost_usd_micros` | `bigint` | |
| `sent_by` | `text` FK → `user` | When a member sent the draft |
| `edited` | `boolean` | |
| `created_at` | `timestamptz` | |

- Members read the trace through `agent_trace_member` (a security-barrier view without model, tokens, or
  cost), like spec 003's `restricted_value_public`.

## 3. Settings and usage

### Changes to `workspace` and `property`

| Table | Column | Rules |
|---|---|---|
| `workspace` | `assistant_autonomy` | `text`, `draft` or `auto`, default `draft` |
| `workspace` | `chat_daily_limit` | `integer`, default 1000 |
| `workspace` | `chat_property_daily_limit` | `integer`, default 200 |
| `property` | `assistant_autonomy` | `text`, null (follow the workspace) or `draft` / `auto` |

### `chat_usage_daily`

| Column | Type | Rules |
|---|---|---|
| `workspace_id`, `property_id` | FKs | `ON DELETE CASCADE` |
| `day` | `date` | UTC |
| `replies` | `integer` | Assistant replies and drafts that used the model |
| `cost_usd_micros` | `bigint` | |
| `limit_notified_at` | `timestamptz` | One owner email per property and day |

- Primary key `(property_id, day)`.

## 4. Security events

| Type | Metadata |
|---|---|
| `assistant.autonomy_changed` | `propertyId` (absent for the workspace default), `autonomy` |
| `conversation.replied` | `propertyId`, `conversationId`, `fromDraft`, `edited` |

## 5. Retention (research R14)

| Data | Kept until |
|---|---|
| `conversation` with messages, drafts, traces | 12 months after the stay's checkout, or after the last message without a stay |
| `chat_usage_daily` | 13 months |
