# Data Model: Guest Guide

**Feature**: [spec.md](spec.md) · **Plan**: [plan.md](plan.md) · **Research**: [research.md](research.md)

One migration pair: `0021_guest_guide.sql` (tables, generated by drizzle-kit) and
`0022_guest_guide_rls.sql` (row-level security, grants, column grants). Every new table is
tenant-owned: it carries `workspace_id`, has RLS enabled and forced, and is covered by the CI RLS
check (SEC-14). Conventions follow features 001 to 003: UUID primary keys, `timestamptz`, `text`
with `CHECK` constraints instead of enums.

Two contexts, as in feature 003 (migration 0019):

- **Request context** (`guidesk_app`, a member's request): members read what the Share screen
  shows; owners and admins write. Token and code ciphertexts are never selectable.
- **System context** (the owner connection): guest routes after resolving a link (research R12),
  the share service when it decrypts a token or code after the request-context checks, and
  `retention.daily`.

## 1. Links

### `guide_link` (the property link)

| Column | Type | Rules |
|---|---|---|
| `id` | `uuid` PK | `gen_random_uuid()` |
| `workspace_id` | `uuid` FK → `workspace` | `ON DELETE CASCADE` |
| `property_id` | `uuid` FK → `property` | `ON DELETE CASCADE` |
| `public_id` | `text` | Unique. `CHECK (public_id ~ '^[a-z2-7]{26}$')` (research R4) |
| `status` | `text` | `active` or `replaced`. Default `active` |
| `created_by` | `text` FK → `user` | `ON DELETE SET NULL`; null when created by the system |
| `created_at` | `timestamptz` | Default `now()` |
| `replaced_at` | `timestamptz` | Set when regenerated; `CHECK ((status = 'replaced') = (replaced_at IS NOT NULL))` |
| `replaced_by` | `text` FK → `user` | `ON DELETE SET NULL` |

- Partial unique index `guide_link_active_uq` on `(property_id) WHERE status = 'active'`.
- Created on first need (the Share screen or the first publish), in the same transaction as a
  check that no active link exists (`ON CONFLICT DO NOTHING` on the partial index, then re-select).
- **Transitions:** `active → replaced` (FR-019). Never back.
- **RLS:** every member of the workspace selects; owners and admins insert and update while the
  workspace is active. No deletes in the request context.

### `stay_link`

| Column | Type | Rules |
|---|---|---|
| `id` | `uuid` PK | Generated by the application before encrypting (the vault AAD binds the row ID) |
| `workspace_id` | `uuid` FK → `workspace` | `ON DELETE CASCADE` |
| `property_id` | `uuid` FK → `property` | `ON DELETE CASCADE` |
| `stay_id` | `uuid` FK → `stay` | `ON DELETE CASCADE` |
| `token_hash` | `text` | Unique. SHA-256 hex of the token. `CHECK (token_hash ~ '^[0-9a-f]{64}$')` |
| `token_ciphertext` | `bytea` | Vault ciphertext of the 43-character token. Not selectable by `guidesk_app` |
| `data_key_id` | `uuid` FK → `workspace_data_key` | The data key that encrypted the token and the code |
| `confirmation_ciphertext` | `bytea` | Vault ciphertext of the 6-character code; null until the property requires one. Not selectable by `guidesk_app` |
| `status` | `text` | `active`, `revoked`, or `replaced`. Default `active` |
| `created_by` | `text` FK → `user` | `ON DELETE SET NULL` |
| `created_at` | `timestamptz` | Default `now()` |
| `last_copied_at` | `timestamptz` | Updated on each copy (FR-022) |
| `last_copied_by` | `text` FK → `user` | `ON DELETE SET NULL` |
| `ended_at` | `timestamptz` | Set when revoked or replaced; `CHECK ((status = 'active') = (ended_at IS NULL))` |
| `ended_by` | `text` FK → `user` | `ON DELETE SET NULL` |
| `failure_count` | `smallint` | Default 0. Wrong codes in the current window, all devices (research R8) |
| `failure_window_started_at` | `timestamptz` | Start of the current 15-minute failure window |
| `locked_until` | `timestamptz` | Verification refused until then |
| `lockout_count` | `smallint` | Default 0. Lockouts in the last 24 hours, for the backoff |
| `last_lockout_at` | `timestamptz` | Resets `lockout_count` after 24 quiet hours |

- Partial unique index `stay_link_active_uq` on `(stay_id) WHERE status = 'active'` (one working
  link per stay, FR-020).
- Index `stay_link_property_idx` on `(property_id, status)`.
- **Transitions:** `active → revoked` (host revokes); `active → replaced` (host regenerates, a new
  `active` row is created in the same transaction). A stay link also stops working, without a status
  change, when its stay is cancelled, hidden, or deleted (cascade) or its window closes (research R6).
- **Validation:** a stay link can only be created for a stay of the same workspace and property whose
  status is `active` and whose window has not closed (checked in the service and by a trigger that
  compares `workspace_id` and `property_id` with the stay's).
- **RLS:** owners and admins select (excluding the two ciphertext columns), insert, and update while
  the workspace is active. Agents see no rows (FR-044, AC-SEC-008).

## 2. Guest sessions

### `guide_session`

| Column | Type | Rules |
|---|---|---|
| `id` | `uuid` PK | |
| `workspace_id` | `uuid` FK → `workspace` | `ON DELETE CASCADE` |
| `property_id` | `uuid` FK → `property` | `ON DELETE CASCADE` |
| `stay_link_id` | `uuid` FK → `stay_link` | `ON DELETE CASCADE` |
| `cookie_hash` | `text` | Unique. SHA-256 hex of the cookie value. `CHECK (cookie_hash ~ '^[0-9a-f]{64}$')` |
| `verified_at` | `timestamptz` | Set when the device enters the right confirmation code |
| `created_at` | `timestamptz` | Default `now()`. The device's first open |
| `last_seen_at` | `timestamptz` | Updated at most once per 5 minutes |

- Index `guide_session_link_idx` on `(stay_link_id)` (device count, FR-025).
- No network address, user agent, or other device detail (FR-050, SEC-20).
- A session is valid only while its stay link is working; nothing else ends it (research R6).
- When the stay link is regenerated, the old link's sessions stay attached to the replaced link and
  therefore stop working; the guest opens the new link to get a new session.
- **RLS:** owners and admins select (for the device counts on the Share screen). Writes only in the
  system context.

## 3. Settings

### Change to `guide` (from feature 003)

| Column | Type | Rules |
|---|---|---|
| `require_confirmation_code` | `boolean` | Default `false` (FR-033) |

- Turning it on generates a confirmation code for every active stay link of the property in the
  same transaction (in the system context, after the request-context role check); turning it off
  keeps the codes (so turning it on again does not change codes already sent) but stops asking.
- Existing RLS on `guide` applies; owners and admins update it.

## 4. View counts

### `guide_open_daily`

| Column | Type | Rules |
|---|---|---|
| `workspace_id` | `uuid` FK → `workspace` | `ON DELETE CASCADE` |
| `property_id` | `uuid` FK → `property` | `ON DELETE CASCADE` |
| `day` | `date` | In the property's time zone |
| `link_kind` | `text` | `property` or `stay` |
| `opens` | `integer` | `CHECK (opens >= 0)` |

- Primary key `(property_id, day, link_kind)`.
- Written only in the system context with `INSERT … ON CONFLICT DO UPDATE SET opens = opens + 1`.
- **RLS:** every member selects.

## 5. Security events

New types in `packages/domain/src/security-events.ts`, with metadata allowlists (no key may match
`code|otp|token|secret|password|cookie`):

| Type | Actor | Metadata |
|---|---|---|
| `guide.property_link_regenerated` | member | `propertyId` |
| `guide.stay_link_copied` | member | `propertyId`, `stayId` |
| `guide.stay_link_regenerated` | member | `propertyId`, `stayId` |
| `guide.stay_link_revoked` | member | `propertyId`, `stayId` |
| `guide.confirmation_changed` | member | `propertyId`, `required` |
| `guide.verification_locked` | none | `propertyId`, `stayId`, `lockedMinutes`, `lockouts` |
| `restricted_value.guest_revealed` | none | `propertyId`, `fieldId`, `kind`, `stayId` |
| `restricted_value.exported` | member | `propertyId`, `stayId`, `fields`, `language` |

The reveal history of a property (feature 003) lists `restricted_value.revealed`,
`restricted_value.guest_revealed`, and `restricted_value.exported`. Guest events carry no IP hash,
location, or user agent.

## 6. Derived views (no tables)

- **Published guide view** (research R11): feature 003's published preview for one language, plus the
  property's time zone, country, check-in and checkout times, guide languages, the public Wi-Fi
  value when made public, benefit flags on recommendations, and guest media addresses.
- **Lock state** of a session (research R6): `public`, `before` (`opensAt`), `inside` (with
  `verified` and `codeRequired`), `ended`, computed per request from `stay_link`, `stay`, `property`,
  and `guide`.
- **Stay row on the Share screen:** the stay (dates, channel, may-be-block), its active or latest
  stay link status, device count, first opened (`min(guide_session.created_at)`), values shown
  (count of `restricted_value.guest_revealed` for the stay), and `locked_until`.

## 7. Retention (research R16)

| Data | Kept until |
|---|---|
| `stay_link` and its `guide_session` rows | 30 days after the stay window closes, or after `ended_at`, whichever is first |
| `guide_link` rows with status `replaced` | 30 days after `replaced_at` |
| `guide_open_daily` | Until spec 010 sets a period (counts only) |
| Rate-limit buckets for guest routes | As today (expired windows are removed daily) |
| Security events | Feature 001 retention |
