Draft v0.1 · low fidelity · provisional · last updated 2026-11-14

What this is

Twelve key mobile screens, drawn as grey boxes to agree on structure, content, and behavior before any visual design. The visual brand is not decided (OQ-11), so colors, names, and the logo are placeholders.

The sample property is fictional: Casa Colibrí, Playa Sámara, Guanacaste, Costa Rica. Host: Ana. Guest: Emily. All names are fictional.

Details: user flows · screen inventory · design system · principles and IA.

How to read it

  • Crossed grey boxes are photos or images.
  • Numbered circles 1 match the notes under each screen.
  • Dashed pills are commission disclosures (PC-07).
  • Dashed boxes with a lock are restricted fields (SEC-01 to SEC-04).
  • Screen IDs (for example G-01) refer to the screen inventory.
